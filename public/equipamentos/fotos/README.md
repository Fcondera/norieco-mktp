# Fotos reais do PDV completo

Adicione aqui fotos JPG, PNG ou WebP do kit e liste os arquivos em
`public/equipamentos/pdv-completo.json`, por exemplo:

```json
{
  "photos": [
    { "src": "/equipamentos/fotos/kit.webp", "alt": "PDV completo com computador, monitor, teclado, mouse e impressora" },
    { "src": "/equipamentos/fotos/computador.webp", "alt": "Computador do kit PDV" },
    { "src": "/equipamentos/fotos/impressora.webp", "alt": "Impressora incluída no kit" }
  ]
}
```

Também são aceitas URLs HTTPS. A primeira foto aparece no card da landing page.
Enquanto a lista estiver vazia, a página exibe espaços identificados para as
fotos, sem imagens fictícias ou links quebrados. Não há foto de estoque publicada.
