# Halloween NoriEco

Original 3D artwork generated for this website: a friendly ghost, violet moon,
illuminated orange/purple pumpkins and fog, plus an isolated floating ghost.
No third-party brand assets are used.

WebP exports preserve alpha transparency. Hero exports: 1200×800 and 700×467;
decorative ghost: 280×280. Image sources remain in the generation archive;
the website loads only these workspace assets. All images are decorative, with
empty alt text and reduced-motion support in CSS.

Interactive ornament: coffin-open.webp and coffin-lid.webp (640 square),
pumpkin.webp (420 square) and bat.webp (200 square), generated specifically
for NoriEco. The accessible button opens on mouse hover or touch/keyboard
activation. CSS animates the lid, bat flights and gentle candle glow; reduced
motion disables these animations. The official NoriEco logo is unchanged.
